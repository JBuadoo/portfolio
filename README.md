# JB Study: Interactive Pixel-Art Portfolio

Joseph K. Buadoo's portfolio, built as an explorable pixel-art study. The bookshelf is the navigation: click a book and it slides off the shelf, flies forward, swings open on its spine, and its pages turn as two-sided 3D leaves.

## Run it

```bash
npm install
npm run dev        # local dev server (Vite)
npm run build      # type-check + production build to dist/
npm run preview    # serve the production build
```

`dist/` already contains a ready-to-host build. Copy it to any static host, such as GitHub Pages, or serve it locally with `npx serve dist`. All paths are relative, so the site works from a sub-folder.

## Editing content

All portfolio text lives in **`src/data/books.ts`**. Each book has `entries`, each entry has `spreads`, and each spread has a `left` and a `right` page made of blocks (`title`, `p`, `list`, `meta`, `tags`, `image`, `gallery`, `feature`, `links`, `code`, `audio`, `placeholder`, and so on; see `src/data/types.ts`).

- **To replace a placeholder,** swap the `{ t: "placeholder", ... }` block for an `image` or `gallery` block.
- **To add an image,** put it in `public/assets/projects/` (WebP preferred) and reference it with `img("file-name", "alt text")`.
- **The table of contents and page numbers** are generated automatically.

## Architecture

| Area | Files |
| --- | --- |
| Scene (layered sprites, scaled with crisp pixels) | `components/StudyEnvironment.tsx`, `WindowLighting.tsx` (light shafts + dust canvas), `Bookshelf.tsx`, `PortfolioBook.tsx` |
| Book | `components/OpenBook.tsx` (flight, cover, page turns, closing, keyboard and swipe), `BookPage.tsx`, `TableOfContents.tsx`, `ProjectCard.tsx`, `ProjectGallery.tsx` (lightbox), `AudioSnippets.tsx` |
| Shell | `App.tsx` (intro auto-open, book switching, routing), `Navigation.tsx`, `LoadingScreen.tsx`, `MobileExperience.tsx` |
| Lib | `lib/route.ts` (hash router: `#/uiux/tap-in/2`), `lib/motion.ts` (Web Animations helpers), `lib/spreads.ts` |

Animations use the native Web Animations API and CSS 3D transforms, so there is no animation library and the bundle stays small. `prefers-reduced-motion` swaps the flights and turns for quick fades.

## Pixel art pipeline

Every sprite is generated by code in `art/`:

- `art/generate.py` draws each layer: wall with overscan, sky, clouds, skylines, window, decor, shelf, the five book covers, the leather and parchment 9-slices, and the UI frames. It also writes `src/data/sceneManifest.json`, which holds the layer positions.
- `art/icons.py` holds the hand-drawn pixel icons (exported to `src/data/pixelIcons.json`).
- `art/glyphs.py` and `art/build_font.py` build **JB Pixel**, the custom bitmap display font.

To regenerate after editing the art, run `npm run assets` (needs Python 3 with Pillow and fontTools).

## Keyboard

- `←` / `→` turn pages
- `Home` jumps to the contents
- `Esc` closes the book (or the lightbox)
- Every shelf book, journal, TOC entry and control can be reached with Tab
